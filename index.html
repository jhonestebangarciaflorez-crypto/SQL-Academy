¿Qué es SQL?

SQL Básico 5 min de lectura • Actualizado 2024

SQL (Structured Query Language) es el lenguaje estándar para gestionar y manipular bases de datos relacionales. Fue desarrollado en los años 70 por IBM y hoy es ampliamente adoptado en sistemas como PostgreSQL, MySQL, SQLite y SQL Server. Con SQL puedes crear, leer, actualizar y eliminar datos de manera declarativa: describes qué quieres, no cómo obtenerlo.


SQL opera sobre tablas — estructuras bidimensionales de filas y columnas — organizadas dentro de una base de datos. Cada tabla representa una entidad del dominio (clientes, pedidos, productos) y las relaciones entre ellas se expresan mediante claves primarias y claves foráneas.

Sintaxis oficial

SQL SYNTAX 
SELECT columna1, columna2
FROM nombre_tabla
WHERE condicion
ORDER BY columna1 ASC;
