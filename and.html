AND, OR, NOT

SQL Básico 5 min de lectura • Actualizado 2026

Los operadores lógicos AND, OR y NOT combinan múltiples condiciones en WHERE. Esta es una de las herramientas más utilizadas en consultas SQL del mundo real.


Combina este operador con WHERE, ORDER BY y otras cláusulas para construir consultas potentes y expresivas.

Sintaxis oficial

SQL SYNTAX 
SELECT *
FROM Clientes
WHERE pais = 'España'
AND ciudad = 'Madrid';
